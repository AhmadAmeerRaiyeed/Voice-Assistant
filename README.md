🎙️ Voice Assistant (Web-Based)
📌 Overview

This project is a web-based Voice Assistant built using HTML, CSS, and JavaScript. It can recognize user voice commands and respond with actions like searching the web, opening websites, telling time/date, and more.

The goal of this project is to demonstrate speech recognition + browser automation using pure frontend technologies.

🚀 Features
🎤 Voice command recognition
🔊 Text-to-speech response
🌐 Open popular websites (Google, YouTube, etc.)
🔍 Search queries on the web
🕒 Tell current time and date
💬 Interactive responses
🛠️ Tech Stack
HTML5 – Structure
CSS3 – Styling & UI
JavaScript (Vanilla JS) – Logic & functionality
Web Speech API – Speech recognition & synthesis
📂 Project Structure
voice-assistant/
│── index.html
│── style.css
│── script.js
│── assets/
⚙️ How It Works
User clicks on the microphone button 🎤
Browser captures voice input using SpeechRecognition API
JavaScript processes the command
Assistant performs an action or responds using SpeechSynthesis API
▶️ How to Run
Clone the repository:
git clone https://github.com/your-username/voice-assistant.git
Open the project folder:
cd voice-assistant
Run index.html in your browser

⚠️ Note: Use Google Chrome for best compatibility.
